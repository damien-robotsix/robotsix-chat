Fixed chat turns intermittently failing with an internal error. The Claude SDK session was bound with `ClaudeAgentOptions.session_id` on every turn — the option that *creates* a session under a chosen id — so every turn after the first asked the CLI to create an id whose transcript already existed and was refused with "Session ID … is already in use". Subsequent turns now use `resume`, which is the option that continues a session, and a binding mismatch in either direction self-heals instead of failing the turn.
