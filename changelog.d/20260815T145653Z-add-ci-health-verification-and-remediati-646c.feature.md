Added three direct-repository tools for diagnosing and remediating CI failures that block a dependent PR from merging: `check_ci_health` (classify recent CI history for a branch and confirm whether a failure is pre-existing on the base branch), `rerun_ci_workflow` (confirmation-gated re-run of a failed workflow run), and `file_ci_stabilization_ticket` (file a dedicated CI-stabilization ticket on the board). The underlying GitHub Actions client now distinguishes "no workflow runs found" from "GitHub Actions API unreachable", so the health check and re-run tools surface API errors instead of a misleading "no runs" message.
