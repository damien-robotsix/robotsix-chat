Reach fleet components at the internal `base_url` published by the central-deploy roster instead of at public URLs with injected HTTP basic-auth credentials. The `fleet_auth` setting is removed: the roster is the single place recording which components the agent may reach, populated by each component's chat-access toggle. Requests stay on the container network, so no credential exists to provision, rotate, or leak — and the fleet's SSO-only edge, which no longer accepts basic auth, is never involved.
