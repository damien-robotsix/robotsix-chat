`component_request` now falls back to `central_deploy.api_token` when a component has no `component_credentials` entry of its own (header auth only — Basic needs a username/password pair, which a single token cannot supply). Components behind the deploy plane all authenticate with that one token, so requiring a per-component copy of it meant every config rewrite that dropped an entry silently removed access: `github` lost its entry on 2026-08-08 and both entries were lost on 2026-07-30. A per-component entry still wins where one is set.
