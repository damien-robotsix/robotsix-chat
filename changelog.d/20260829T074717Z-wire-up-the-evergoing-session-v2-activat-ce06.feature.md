Wire up the evergoing session: a single never-ending chat session that can be activated via `evergoing.enabled`. When enabled, exactly one evergoing session is created on boot (never auto-closed or evicted) and a background scheduler runs every `evergoing.trim_interval_seconds`, checking a new-input gate first (no-input intervals make zero LLM calls) and otherwise using a cheap summary-tier model to physically trim finished, off-subject leading turns while always preserving the in-flight turn. The UI marks the evergoing session distinctly and renders its post-trim transcript.
