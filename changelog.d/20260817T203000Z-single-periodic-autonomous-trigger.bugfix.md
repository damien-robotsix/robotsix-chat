Autonomous presets now have exactly one scheduling model. The `on_close` trigger is retired — every preset is periodic and waits `trigger_interval_seconds` (default 1 h), so `default` no longer behaves differently from the others. The schedule is also now honoured and persisted: `ensure_active_session` used to spawn unconditionally, which meant closing a daily preset restarted it within seconds and every server restart re-ran all of them (three autonomous sessions ran in parallel where one was expected). Existing configs naming `trigger_type` still load; `on_close` presets adopt the standard interval.
