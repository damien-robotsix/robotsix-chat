Fix the `file_ticket` tool, which could never file a ticket. It wrapped its payload in a list before POSTing to mill's `/tickets/ingest`, but that endpoint takes a single `TicketIngest` object, so every call returned 422. `repo_id` is now required with an actionable error instead of being documented as optional (mill has no default repo: a missing value is a 422, an empty one a 404). Also bumps the `robotsix-http` pin so a read-timed-out POST is no longer retried into a duplicate side effect.
