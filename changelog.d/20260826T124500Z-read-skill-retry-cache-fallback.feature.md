The `read_skill` tool now retries transient loader failures up to 3 times with exponential backoff (0.1 s, 0.2 s) before falling back to a stale cached body.  When a skill body was successfully loaded earlier in the session and a later load fails, the cached copy is served so the agent can continue working.  If no cache exists and all retries are exhausted, the error message guides the agent to inform the user that the skill is temporarily unavailable and offer alternative approaches.
