Docs: stop advertising a `DEPLOY_API_KEY` environment variable for the central-deploy roster call. Nothing in the codebase has read it since `feedback.deploy_api_key` replaced it; the only thing keeping it alive was this paragraph and a matching entry in the deploy-plane env store, which held a live credential that no code consumed. The config standard forbids first-party credentials in `environment:` precisely because two open channels for one value make "why is this value what it is" unanswerable. The deploy-plane entry has been removed fleet-side.
