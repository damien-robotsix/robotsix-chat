An autonomous session the operator was chatting with is no longer deleted and replaced mid-conversation. An autonomous run finishes within minutes but its card stays on screen for the rest of the trigger interval, so the session the operator opens is usually one already marked `completed` — and the next restart fire retired it (destroying its history) to make room for a fresh one. An operator turn now reopens the session and holds the preset off until the conversation goes quiet; the retire sweep spares any session spoken to recently; and deleting a session for one owner no longer destroys a conversation another owner still holds, which had left the operator typing into a silently re-created blank chat. Restart timers are also deduplicated per owner — a completion and a close/delete could each arm one, and the superseded timer still fired, spawning replacements at roughly twice the configured interval.
