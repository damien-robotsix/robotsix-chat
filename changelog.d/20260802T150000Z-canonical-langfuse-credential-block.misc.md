**Breaking (config):** Langfuse credentials move to the canonical component-standard block. `langfuse` is now `{host, projects}`, where `projects` maps a Langfuse **project name** to `{public_key, secret_key, project_id}` — this component declares `robotsix-chat` (main agent) and `robotsix-chat-cognee` (memory subsystem). The old single-project `langfuse.{public_key, secret_key}` fields and the whole `memory.langfuse` block are **removed**; `memory.langfuse_project` now names which project cognee's own LLM traffic traces to, and its credentials are resolved from the top-level block. One standard block per component is what lets central-deploy enumerate the fleet's Langfuse credentials uniformly and dispatch them to the consumers that need them (the chat trace proxy, cost-monitor's reconciliation) — previously every component invented its own layout and discovery silently found nothing. Config models are `extra="forbid"`, so the config file and the image must be updated together.
