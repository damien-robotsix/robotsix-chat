`render_pdf_page` now actually reaches the model as a viewable image. The tool already returned a `BinaryContent` image block, but robotsix-llmio's Claude-SDK tool bridge coerced every tool result with `str(result)` — so a 205 KB rendered page arrived as a 588,111-character repr of its raw bytes, unreadable at any DPI. Bumping robotsix-llmio to `13a53e48` picks up the MCP `image` block mapping; the accompanying robotsix-http bump to `cdfd4d1c` is required with it (0.3.2 renamed `_compute_backoff` to the public `compute_backoff`) and also fixes `RuntimeError: asyncio.run() cannot be called from a running event loop` when a sync `call_with_retry` is reached from async code.
