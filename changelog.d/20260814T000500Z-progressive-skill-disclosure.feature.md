Skill instructions are no longer concatenated into the system prompt in full. The prompt now carries a one-line summary per skill plus a `read_skill(name)` tool that serves the full body on demand, cutting the skill payload from 85 KB to ~5 KB on every request. This also removes a hard failure: the Claude Agent SDK passes the system prompt as a single `--system-prompt` argv element, and the kernel caps one argument at 128 KiB (`MAX_ARG_STRLEN`), so autonomous sessions had begun failing to start with `E2BIG`.
