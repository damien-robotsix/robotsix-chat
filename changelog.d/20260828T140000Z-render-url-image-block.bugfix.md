`render_url` now returns the page screenshot as a viewable image instead of base64 text. It previously encoded the PNG into `screenshot_base64` inside a JSON *string*, so the transport stringified it and the model received an unreadable blob rather than a picture — the same defect that made `render_pdf_page` useless. The screenshot is also capped at ~750k pixels, since a `full_page` capture of a long document was unbounded and could exceed the model's per-image limit. `text_only=True` is unchanged and still returns compact JSON. Pillow is now a declared dependency: it was imported by name in `pdf_tools` and worked only because pypdfium2 pulls it in transitively.
