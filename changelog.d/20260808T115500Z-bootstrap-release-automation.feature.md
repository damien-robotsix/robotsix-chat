New `robotsix-`-prefixed repos created through chat now get release automation wired at creation time: the `RELEASE_APP_ID` variable, the `RELEASE_APP_PRIVATE_KEY` secret, and `.github/workflows/auto-release.yml`. robotsix-standards `changelog-driven-releases.md` §4 requires every repo to wire the shared auto-release workflow, and a fleet sweep found nine that never had — so none of them had ever cut a release tag. An existing workflow is never overwritten, and a bootstrap failure is reported without failing the repo creation.
